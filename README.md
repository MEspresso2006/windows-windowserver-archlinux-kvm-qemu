# Windows and Windows Server on Arch Linux with KVM/QEMU
## Overview

I will document all the steps and my thoughts about setting up a Windows virtualization lab on Arch Linux using KVM/QEMU, libvirt, and virt-manager.
The main goal of this project is to create an environment where I can run Windows Server and Windows 11 virtual machines for my future Active Directory Security Lab. 
In this project, I will work with virtual networking, storage pools, UEFI, snapshots, cloning, and remote management.
For this project, I chose KVM/QEMU mainly because it's well integrated with Linux and gives me more control over the virtualization environment.
